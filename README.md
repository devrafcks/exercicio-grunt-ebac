# Exercício EBAC - Automação com Grunt

Este projeto é um exercício prático proposto pela EBAC para demonstrar a automação de tarefas de desenvolvimento front-end utilizando **Grunt.js**.

---

## Proposta do Exercício

O objetivo principal deste exercício é:

1.  **Criar e configurar um `Gruntfile.js`**: Um arquivo de configuração para o Grunt que define as tarefas de automação.
2.  **Compilar LESS para CSS**: Automatizar o processo de transformação de arquivos `.less` (pré-processador CSS) em arquivos `.css` prontos para uso no navegador.
3.  **Comprimir Código JavaScript**: Reduzir o tamanho de arquivos `.js` para otimizar o carregamento e desempenho da aplicação.
